# 🔐 Password Generator

A simple and responsive **Password Generator Web Application** built using **HTML, CSS, and JavaScript**.  
This tool helps users create **strong, secure, and random passwords** to improve online security.

---

## 🚀 Features

✔ Generate strong random passwords instantly  
✔ Adjustable password length  
✔ Include uppercase letters (A–Z)  
✔ Include lowercase letters (a–z)  
✔ Include numbers (0–9)  
✔ Include special characters (!@#$%^&*)  
✔ Copy generated password to clipboard  
✔ Responsive and user-friendly interface  

---

## 🛠️ Technologies Used

- **HTML5** – Page structure  
- **CSS3** – Styling and layout  
- **JavaScript** – Password generation logic
